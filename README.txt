SWIFTPAY GLOBAL — PHONE-ONLY PWA PROTOTYPE

CONTENTS
- index.html: app interface and simulated functionality
- manifest.webmanifest: installable PWA metadata
- sw.js: offline caching service worker
- icon.svg: app icon

RUN ON ANDROID
1. Extract this ZIP using your phone's file manager.
2. Open index.html in a browser to preview (some PWA features need hosting).
3. For install/offline support, host the folder on an HTTPS static host such as GitHub Pages.
4. On GitHub mobile site, create a repository, upload all four files, then enable Pages in repository Settings > Pages.
5. Open the published HTTPS site in Chrome and use menu > Add to Home screen / Install app.

DEMO SAFETY
All balances, exchange rates, crypto holdings and transfers are fictional and stored only in the page's JavaScript memory. No real money moves. Refreshing resets the demo balances. This is not a bank, payment service, exchange, custody wallet, or financial advice.
Do not enter real personal, banking, card, password, or OTP data.

CUSTOMIZATION
Edit index.html with Acode or another Android text editor. Search for "SwiftPay" to change branding and search for "rates" and "balances" to adjust demo values.
